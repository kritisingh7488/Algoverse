# AlgoVerse — Asset & Illustration Guide

> Purpose
>
> This document defines every visual asset used throughout AlgoVerse.
>
> Assets include
>
> - mascots
> - illustrations
> - icons
> - backgrounds
> - decorative graphics
> - patterns
> - Lottie animations
> - SVGs
>
> Every AI coding agent must follow this document before adding, replacing, or modifying visual assets.
>
> Visual assets should strengthen the AlgoVerse identity while maintaining performance, consistency, accessibility, and licensing compliance.

---

# Asset Philosophy

Visual assets should

- support learning
- create delight
- reinforce the brand
- reduce intimidation
- improve usability

Visual assets should never exist purely for decoration.

Every illustration should have a purpose.

---

# Asset Priority

Preferred formats

1. SVG

2. Lottie

3. Optimized WebP

4. Optimized PNG

Avoid

JPEG

Large PNG

Animated GIF

Heavy videos

---

# Illustration Style

All illustrations should share one visual language.

Characteristics

- Rounded
- Soft
- Pastel
- Friendly
- Flat
- Minimal outlines
- Expressive faces
- Clean geometry
- Premium appearance

Avoid

- Realistic drawings
- Anime style
- Pixel art
- Cartoon with thick outlines
- Comic style
- Photographs

# Illustration Behaviour

Illustrations should

Fade in

Float gently

Support theme switching

Never cover controls

Never block content

Never reduce readability

---

# Performance

Every asset must

Be optimized

Lazy loaded where appropriate

Compressed

Cached

Responsive

Prefer inline SVG where possible.

---

# Accessibility

Illustrations are decorative unless they communicate essential information.

Decorative assets should use

aria-hidden="true"

Informative illustrations require meaningful alt text.

Respect reduced motion settings.

---

# Licensing

Preferred Sources

- Open Doodles
- OpenMoji
- SVG Repo
- Lucide
- Heroicons
- Tabler Icons
- Hero Patterns
- Google Fonts

Avoid copyrighted artwork.

Never use assets without verifying the licence.

Maintain attribution where required.

---

# AI Rules

Never introduce a new illustration style.

Never mix icon packs.

Never randomly place mascots.

Never overload pages with decorative assets.

Reuse approved assets.

If a new illustration is required,

ensure it matches the existing visual language before implementation.

---

# Definition of Complete

The asset system is complete only if

✓ Every page follows the mascot placement guide.

✓ Every page uses approved icons.

✓ Every illustration matches the established style.

✓ Assets remain lightweight.

✓ Assets support both themes.

✓ Performance remains high.

✓ Licensing requirements are satisfied.

✓ Accessibility requirements are satisfied.

---

# Final Principle

Illustrations should make AlgoVerse memorable.

Users should recognise the platform from its mascots, colours, and visual language alone.

The artwork should support learning rather than distract from it.

Consistency is more valuable than quantity.
