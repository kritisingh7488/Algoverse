# AlgoVerse — UI Theme Specification

> Purpose
>
> This document defines the visual identity of AlgoVerse.
>
> Every AI coding agent MUST read this document before implementing, modifying, or redesigning any frontend page.
>
> This file is the single source of truth for the application's visual language, emotional experience, mascot philosophy, and overall aesthetic direction.
>
> If any UI implementation conflicts with this specification, this document takes precedence unless explicitly overridden by the user.

---

# Theme Name

AlgoVerse

**Cute Algorithm Adventure**

---

# Core Vision

AlgoVerse should not feel like a traditional coding website.

It should not resemble

- LeetCode
- HackerRank
- GeeksforGeeks
- Codeforces
- Generic Admin Dashboards

Instead, it should feel like a place students genuinely enjoy visiting every day.

Learning algorithms should feel like progressing through a cozy adventure rather than completing homework.

---

# Theme Philosophy

AlgoVerse combines four inspirations into one unique identity.

## Cozy Study Space

Warm.

Relaxing.

Comfortable.

Inviting.

Like sitting at a beautiful study desk with notebooks, coffee, plants, and soft lighting.

---

## Adventure Game

Every lesson feels like progress.

Users should feel rewarded for learning.

Algorithms become "quests."

Achievements become "badges."

Progress feels meaningful.

---

## Notebook Inspiration

The interface subtly references notebooks through

- paper tabs
- sticky notes
- bookmarks
- page separators
- small doodles
- handwritten accents

The notebook inspiration should remain elegant.

The application must never resemble an actual scanned notebook.

---

## Cute Mascot World

AlgoVerse has its own mascot system.

Cats accompany users throughout their learning journey.

Mascots celebrate progress.

Provide encouragement.

Reduce the intimidation of learning algorithms.

Animations explain.

---

# Notebook Inspiration Rules

Notebook inspiration must remain subtle.

Allowed

• Sticky notes

• Page tabs

• Small doodles

• Paper cards

• Binder rings (only where appropriate)

• Washi tape

• Tiny handwritten labels

Avoid

• Dirty paper textures

• Excessive notebook lines

• Torn paper everywhere

• Overly realistic paper scans

The website must remain premium.

Even after hundreds of features are added,

AlgoVerse must still feel

Simple.

Coherent.

Friendly.

Approachable.

---

# Definition of Success

The theme is considered successful if

A user can identify AlgoVerse from a single screenshot.

Users enjoy exploring the interface.

Animations improve understanding.

Mascots become memorable.

Learning feels rewarding.

The interface remains timeless instead of following short-lived trends.

---

# AI Implementation Rules

Every AI coding agent must

Read this document before modifying UI.

Follow the established visual identity.

Never redesign individual pages independently.

Never introduce conflicting styles.

Never use random colors.

Never use inconsistent spacing.

Never replace the mascot system.

Never introduce another visual theme.

Whenever uncertain,

follow this document before making design decisions.
