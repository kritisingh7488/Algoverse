# AlgoVerse — Mascot System

> Purpose
>
> This document defines the mascot system used throughout AlgoVerse.
>
> The mascot system is a core part of the product identity.
>
> Every AI coding agent must follow this document whenever implementing illustrations, decorative elements, achievements, onboarding screens, empty states, loading states, or dashboard components.
>
> Mascots are educational companions.
>
> They should guide, encourage, celebrate progress, and reduce the intimidation of learning algorithms.
>
> Mascots should never become visual clutter.

---

# Mascot Philosophy

AlgoVerse is a learning adventure.

Students should never feel like they are learning alone.

The mascot system exists to create companionship throughout the learning journey.

Every mascot should feel

Friendly

Curious

Supportive

Playful

Comfortable

Calm

Never childish.

Never distracting.

Never annoying.

---

# Theme Switching

Mascots automatically change with the application theme.

Light Theme

Blue Cat

Black Cat

Dark Theme

Orange Cat

White Cat

The same mascot role remains.

Only the artwork changes.

Theme switching should smoothly crossfade between mascot variants.

One primary mascot.

Optional secondary decorations.

Two visible mascots per screen.

Hero mascot

Small supporting mascot

No additional mascots.

# Accessibility

Mascots must never replace important information.

Every illustration should remain decorative.

Screen readers should not depend on mascot artwork.

Animations must respect reduced motion settings.

---

# Asset Rules

Preferred format

SVG

Fallback

Lottie

PNG only if necessary.

Illustrations should remain lightweight.

Avoid large raster images.

---

# Consistency Rules

Every mascot should

Use the same illustration style.

Use the same proportions.

Share the same visual language.

Match the current theme.

Never mix illustration styles.

Never introduce additional mascot species.

Cats are the permanent identity of AlgoVerse.

---

# AI Implementation Rules

Every AI coding agent must

Reuse existing mascot assets.

Never randomly position mascots.

Never clutter pages.

Never introduce conflicting illustration styles.

Never redesign mascots independently.

Always preserve mascot consistency throughout the application.

---

# Final Principle

The mascots are not decorations.

They are learning companions.

Every illustration should make users smile without distracting them from learning.
